# Chongqing POS 0.8.3

- Botón «🥡 Para llevar» en la orden de una mesa: lo que se capture se marca para llevar. También se puede marcar o desmarcar cada platillo.
- La comanda dice cómo empacarlo según dónde se imprime: en Cocina y Wok «EN DESECHABLE»; en Barra «VASO DESECHABLE CON TAPA».
- Si toda la comanda es para llevar, sale en grande «*** PARA LLEVAR ***»; si solo algunos platillos, se marca cada uno.
- Nuevo «＋ Producto libre» en la pantalla de captura: un extra o platillo que no está en el menú, con nombre, precio y cantidad. Se puede mandar a Cocina, Wok o Barra, o sin comanda, y se cobra junto con la cuenta.
